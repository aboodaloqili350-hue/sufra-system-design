
# Sufra: System Design Documentation

Software architecture documentation for **Sufra**, a marketplace for
home-cooked food in Jordan.

This repository is the deliverable for **Task 01: Complete System Design
and Software Architecture** (EFTA7 BASTA, Dev Track).

## About Sufra
Sufra connects home cooks with customers who want affordable, trusted,
home-style meals, ordered now or booked for a set time. The first
version includes a Customer app, a Cook app, an admin dashboard, and a
shared backend.
